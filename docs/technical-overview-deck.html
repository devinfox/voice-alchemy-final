The stack

Custom engineered,
hosted on three platforms.

The application

Next.js & React

One codebase covers both the interface people see and the server logic behind it. Fewer parts to maintain, one place to change things.
The platform

Supabase

A managed database that also handles accounts, live updates between users, and file storage for lesson recordings.
The hosting

Vercel

Every change deploys automatically, with preview links before anything reaches students, plus scheduled background jobs.
AI layer
Transcription and analysis run as a server-side API call, which returns structured results the app stores and displays.

Voice Alchemy Academy  ·  Technical Overview09
Trust

Security and reliability

Security
Access is enforced at the database. The data itself will not return rows the person is not entitled to.
Every request is re-checked on the server. What the browser believes about a user's role is never trusted on its own.
Secrets stay server-side. Database and provider keys are never included in anything sent to a browser.
Reliability
Work cannot run twice. Background jobs claim a task exclusively, so a recording is never processed or billed twice.
Scheduled sweeps catch anything missed. If a background step fails quietly, a job running every few minutes finds it and finishes it.
Failures are visible, not silent. Anything that can't complete is recorded with a reason, and retried only when retrying can help.
